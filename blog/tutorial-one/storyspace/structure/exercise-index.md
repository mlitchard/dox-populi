# Exercise index

A persistent panel in the delivered blog: a section of the screen that
holds links to every exercise the reader has reached so far, so a
reader can backtrack to an exercise they skipped. It accumulates as the
reader moves through nodes, and (with the merge model) grows across
stages — each merged stage's exercises join the list. For now it is
this file.

Rule: an exercise appears here once its node has been reached on the
reader's path. Each entry links to the node it lives in and names the
objective it serves.
