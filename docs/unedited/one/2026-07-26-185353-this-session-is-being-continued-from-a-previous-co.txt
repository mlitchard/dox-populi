❯  what's the spec for this vm?                                                 

● dox-populi dev VM — specification

  Purpose: deliver the full dev environment (nix + flakes + the repo +
  toolchain) to people without nix on their host. The Screeps server installs
  and runs inside the VM; the Steam client on the host plays against it.

  Host requirements

  - qemu, tmux, curl — nothing else. run-vm.sh must NEVER invoke or assume nix.
  - Everything is downloaded/built inside the guest by the guest's nix. No
  pre-warming, no host-built disk images, no pre-built artifacts beyond the one
  ISO.

  Delivery (dubai installer-auto-dd pattern)

  - One artifact: dox-populi-installer.iso — built by a maintainer (nix build 
  .#installer-iso), published as a release asset; non-nix users are fully
  self-served (download it or run-vm.sh curls it via ISO_URL).
  - The ISO embeds the repo source and auto-installs with zero human 
  interaction: a systemd service partitions /dev/vda (msdos, single ext4 labeled
   nixos), runs nixos-install --no-root-passwd --flake <embedded repo>#vm,
  powers off. Progress streams to the serial console. Guard: refuses a disk
  that's already partitioned.

  Console UX (dubai vm-session pattern)

  - qemu runs detached in a tmux session, -serial mon:stdio, -display none;
  kernel console=ttyS0.
  - ./run-vm.sh [start] | console | send <cmd> | status | kill — a
  cut/paste-able serial console you can attach/detach (Ctrl-b d); kill cleanly
  stops session + any stray qemu.
  - qemu resolved to an absolute path at start (tmux's PATH differs); fail fast
  if absent.

  Guest (nixosConfigurations.vm)

  - NixOS 25.05-state, hostname dox-populi, user dev/dox-populi (wheel, NOPASSWD
   sudo, getty auto-login), sshd with password auth.
  - Repo seeded to ~/dox-populi on first boot (git init + commit, since apps
  anchor on git rev-parse).
  - fetch-screeps-server: steamcmd wrapper, user's own Steam account (must own
  the game), installs to ~/screeps (outside the steamcmd root —
  force_install_dir is ignored inside it); system sets
  STEAM_SCREEPS_DIR=/home/dev/screeps/server.
  - Optional host dir shared at ~/work (9p, WORKDIR= env, nofail).
  - direnv + nix-direnv; git/vim/curl/jq.

  Networking

  - Host port forwards: 2222→22 (ssh/Remote-SSH), 21025/21026→ Screeps server +
  CLI. Host Steam client plays at localhost:21025. Guest firewall off.

  Secrets (REQUIRED — identical to the native nix workflow)

  - secrix everywhere; decryption is never optional or skipped.
  - Identity keys are always user-provided via SCREEPS_IDENTITY — no key path is
   ever hardcoded. If a secret exists and no identity is set, apps fail with
  instructions. Motd documents keygen + secrix create ... -r <pubkey>.

  Knobs

  MEM (8G), CPUS (4), DISK (./dox-populi.qcow2), DISK_SIZE (40G), ISO, ISO_URL,
  WORKDIR, INSTALL=1 (force installer boot). rm dox-populi.qcow2 = factory
  reset.
